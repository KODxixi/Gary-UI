常见问题

你可能想知道

Atelier 是免费的吗？
入门版永久免费，包含全部 tokens 与排版原语。专业版与团队版提供 14 天试用，试用期内不收取费用。
需要特定的前端框架吗？
不需要。核心是纯 CSS 与语义化 HTML，可直接在任何页面使用。同时我们也提供 React 适配器，方便在组件化项目里按需引入。
可以只使用其中一部分吗？
可以。tokens、排版原语、图标与组件各自独立，你可以只引入需要的部分，不必整体采纳。
支持移动端吗？
所有能力默认响应式。流体刻度与布局原语不依赖固定断点，在手机、平板与桌面都能自然适配。
如何升级或迁移？
升级只需更新 tokens 文件并重新构建。版本遵循语义化版本，破坏性变更会提供迁移脚本与指南，不影响现有页面。
