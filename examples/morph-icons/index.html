GARY-UI / ICON SYSTEM

图标开始 morph。

morphicons 已成为 Gary-UI 的默认图标机制：任意描边图标 morph 到任意描边图标，旋转由数学涌现（2D Procrustes + 极坐标插值），spring 物理驱动，零运行时依赖、全离线。下方按钮点击即切换状态，点击区 44px、描边 1.6px、可访问名称不变。

经典状态对

data-gary-icon + data-gary-icon-to + data-gary-icon-toggle
menu ↔ x
play ↔ pause
sun ↔ moon
chevron-down ↔ up
arrow-right → down
plus ↔ x
volume-2 ↔ volume-x
maximize ↔ minimize-2

arrow-right → arrow-down 的 90° 旋转无需任何声明——Procrustes 在闭式解中检测到全等旋转，系统直接选择纯旋转路径；menu → x 的三条线以最小旋转折叠成对角。

命令式

GaryIcons.morphTo(el, name) · 任意两图标
star

无需预注册状态对：点击下面的“随机变换”，star、bell、calendar、heart、settings、camera、search、message-square、send、external-link 任意两两 morph；动画可被下一次点击打断并保留速度，连点不跳变。

受控 scrub

GaryIcons.seek(el, name, progress) · 不启动调度器
arrow-right → arrow-down · t=0.00

拖动滑块在 arrow-right 与 arrow-down 之间精确 scrub：t=0 完整源形状，t=0.5 旋转到 45°，t=1 完整目标——旋转角度线性插值，中间形状由极坐标插值保持“看着像箭头”而不是收缩畸变。

静态兼容

原有 data-gary-icon 用法不变

减弱动态策略

data-gary-icon-reduced-motion
reducedMotion = user（跟随系统）

morph 是短促的微交互，默认策略 user：系统开启“减弱动态”时自动降级为直切（零帧），其余情况正常 spring。
