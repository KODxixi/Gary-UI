七层阅读结构、节点只写事实、状态词闭集、跨边界绕行 —— 全部继承，不重述。

它只改三条，三条都有实测理由：

| 母本规则 | 本规范 | 为什么改 |
|---|---|---|
| §3.5 虚线 = 未成立 | **虚线 = 非主路径**（辅助输入 / 异步回报 / 跨相位引用） | 过程图的读者问「下一步是谁」，不问「这一侧成立吗」。把辅助输入画成虚线，读者会读成缺口。 |

来源：逆向测量 Arize Phoenix 空状态图（620×290 手写 SVG）的真实属性，不是目测。

## 1. 五层结构

靠「有没有描边 → 描边是虚是实 → 描边多宽 → 填充多深」区分，不用阴影、不用模糊。**报告页玻璃卡的一层柔和落影只负责「浮起来」，不参与分层。**

| 层 | 画法 | 读作 |
|---|---|---|
| 分块 | 1px **虚线**角色色 50% 不透明，不填充 | 阶段 / 作用域 |
| 子帧 | 1px **实线**角色色 50% 不透明 + gray75 填充 + rx4 | 分块里的一个实例组 |
| 卡片 | **2px 实线**角色色 + gray100 填充 + rx8 | 一个对象、一次动作 |
| 条目 | 无描边 + gray200 填充 + rx4 | 卡片或子帧内部的成员 |
| 胶囊 | **2px 实线**角色色 + gray100 填充 + rx=h/2 | 端点（输入/输出/结果），不推进流程 |

分块（1px 虚）与子帧（1px 实）是**两种不同的层**，不能混用：分块切割图面表达阶段，子帧只在分块内部再分一组。
**报告页例外**：嵌进 Gary-UI 报告页时，阶段框退成中性实线（见 §10），虚线只留给边；卡片填充也从 gray100 换成玻璃 `--gary-card-surface-top`。

**子帧这层容易漏，漏了立刻看得出来**：容器里只有条目、没有子帧时，内容只占到容器一半高度，下面空一大块。实测样例就栽在这里——容器 200 高，内容只占 104。

## 2. 几何：全部定值，不按内容撑

| 角色 | 尺寸 | 圆角 |
|---|---|---|
| 卡片 | 120 × 70 | 8 |
| 容器 | 160 × 200 | 8 |
| 内嵌子帧 | 130 × 140 | 4 |
| 条目 | 110 × 28 | 4 |
| 胶囊 | h = 36 | h/2 |

**圆角只有三档：8 / 4 / h/2。** 不出现 6、10、12。

**同角色同尺寸。** 长标签换行或截断，不撑宽框——撑宽的框会让网格失去对齐，读者读不出「这两张是同类」。
**报告页例外**：卡片宽度按整图最长标题 / 副标题自适应（120–260px，全图统一）；先按 14px 量像素，放不下退 12px，仍放不下才截断。**不要按字符数截断**——「7 个字」会把 `DNS 公网解析`、`archos core-flow` 这类本可放下的标签误伤。

## 3. 文字：三档字号，一套基线节奏

| 位置 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 卡片标题 | 14 | 600 | text900 |
| 卡片副标题 | 11 | 400 | text700 |
| 胶囊文字 | 12 | 500 | text900 |
| 条目文字 | 11 | 400 | text900 |

**字号只有 14 / 12 / 11。** 没有 13，没有 10。

**基线节奏固定**：标题 = 框顶 +28，副标题 = 框顶 +48（相距 20），条目文字 = 框顶 + 0.68h。
所有卡片共用这一节奏，**不按框高居中**——居中会让 70 高和 200 高的框文字长得不一样，读者要多花一次判断。

## 4. 配色：四色分工，填充永远灰阶

**色板是独立轴，几何与线型不变。** 选哪个变体由「这张图嵌在哪」决定，不按个人喜好。

### 变体 A · phoenix（独立图页 / 工具界面 / 深色看板）

| 角色 | 描边 | 读作 |
|---|---|---|
| input | `#e67e22` | 数据源 / 输入 / 外料 |
| process | `#2196f3` | 处理 / 任务 / 模型调用 |
| decision | `#9c27b0` | 判定 / 评估 / 评分 |
| result | `#ffbf00` | 结果 / 结论 / 产出 |

实测自 Phoenix 原图，Material 500/700 档。高饱和在近黑底上对比强，四色即可撑起角色分工。

**同族深一档用于「同一角色的下一个环节」**：`#1976d2`（之于 process）、`#7b1fa2`（之于 decision）。
主环节用亮档、其纯产物用深档，读者能看出层级又不引入第二种色相。

### 变体 B · gary（嵌在 Gary-UI 报告页 / 企业面板页内）

| 角色 | 取母本 token |
|---|---|
| input | `--gary-category-2` `#d5af59` |
| process | `--gary-category-1` `#82acec`（深一档未定值，暂不使用） |
| decision | `--gary-category-4` `#be9bda`（深一档未定值，暂不使用） |
| result | `--gary-category-3` `#78c9ac` |

母本 category 色是灰调的，饱和度低一档，在报告页里不会抢数据图的注意力。

### 冲突与判定

Phoenix 变体**不是** Gary-UI token。嵌页验收用 skill 目录里的 `verify_preview_page.py`（不在母本仓；`C:\Users\shiguanyu\AppData\Local\hermes\skills\gary-ui\scripts\verify_preview_page.py`）：它判宿主变量 0、hex 0、每个 `var(--gary-*)` 能在被 link 的 CSS 里找到、HTML 文案 ≥13px。
母本 `agent/checks/invariants.py --page` 只判方角卡片 / 内部编码 / 结论重复，不判颜色与字号；两把尺不要混。

- 嵌进 Gary-UI 页面 → **必须用 gary 变体**，不得出现字面色值。
- 独立工具页 / 深色看板 → 允许 phoenix 变体，但该页不受母本页面闸管辖，**须在交付说明里写明「独立图页，非 Gary-UI 页面」**。

中性阶（dark）：页面底 `#0e0e0e` / 卡片 `#1d1d1d` / 条目 `#303030`；文字 `rgba(255,255,255,.9/.7/.5)`。

**四色封顶。** 同类对象必须同色，不按出现顺序轮转。

### 字号下限的边界

SVG 内文字**不受页面 13px 下限约束**——它是图形标记，随图整体缩放；
但同一页里的 HTML 文案必须 ≥13px。

明说这条的理由：Phoenix 原图 11px 副标题在 620×290 画布上是对的，改成 13px 会让副标题挤爆卡片。
为了过闸把图里的字放大，是拿比例换绿灯。

## 5. 连线：正交折线，直角拐点

| | 描边 | 宽度 | 读作 |
|---|---|---|---|
| 实线 | gray500 `#8d8d8d` | 2 | 主路径 |
| 虚线 | gray400 `#6a6a6a` | 1.5，`dasharray 4 3` | 非主路径 |

端点 marker：`13×13` 水滴、`markerUnits="userSpaceOnUse"`、`refX 11.2`、`refY 6`、`path d="M7.28 3.29 A3.3 3.3 0 1 0 7.28 8.71 L11.2 6 Z"`。
**实线 / 虚线 / 主路径 / 旁支各一套 marker id**：形状同一，fill 分别取主路径亮白、旁支灰、虚线与独立图页的灰。**不能复用同一条实线 marker 给虚线和旁支。**

`refX` 固定 = `11.2`（箭尖贴住目标框边），`refY` 固定 = `6`（中线）。这两个关系不能各改一个——
改一个水滴就会浮离线端或压进框里。

**端点不是三角，也不是圆点**：圆背半径 3.3，从圆上两个切点绕大圆弧回来，两侧切线收成尖头——尾巴的圆弧把线条「收」进去，尖头只负责指方向。它比三角更干净，比圆点更有方向。**这个 `A` 只在 marker 内部；连线仍然禁止弧线与贝塞尔。**

**必须正交折线、直角拐点、半径 0。禁止贝塞尔曲线**——弧线在密集图里读不出「从哪条边进出」。
跨分块必须绕行（母本 §6）：从源框侧边出发，沿分块外侧走到目标，不直穿框。

## 6. 失败条件

违反任一条即不算合规：

- 卡片填充上色
- 连线用角色色
- 用曲线连边
- 一图出现两套中性灰阶（例如再加 `#2a2a2a`）
- 字号出现 13 / 10 / 9
- 圆角出现 6 / 10 / 12
- 给框加投影或发光（独立图页禁止；报告页玻璃卡只允许一层柔和落影，不做发光 / 内高光）
- 用颜色表达好坏 / 成熟度 / 风险

## 7. 怎么验

```bash
python scripts/check_flow_diagram.py <file.svg|file.html>
python scripts/check_flow_diagram.py --self-test    # 证明闸会红
```

**样式闸**七项：stroke 在色板内、fill 在 {gray75,gray100,gray200,none} 内、rx ∈ {4,8,h/2}、
font-size ∈ {11,12,14}、实线 2px / 虚线 1.5px 带 dasharray、有 marker、每条 line/polyline 有 marker-end。

**几何闸**三项：任意两个 rect 不得重叠（包含关系放行）、所有图元在 viewBox 内、连线不得穿过卡片/胶囊（1px 分块/子帧允许被垂直穿越）。

几何闸是后补的，因为漏了它出过一次真事故：一张 27 元素「全部合规」的样例里，
结论胶囊压住判定卡 10px、容器底部空 51px——**样式判据看不见位置，闸全绿而图是坏的**。

**只看到全绿不构成证据**——`--self-test` 会拿手写反例跑出红，证明闸抓得住。

## 7.1 画图时的四条位置规则

闸能抓重叠、出界、穿卡，抓不到「读起来别扭」。这四条靠手工保证：

1. **胶囊离卡片留 ≥18px**，否则端点水滴挤在框边，读者看不出线接在哪。
2. **辅助线从源节点边缘出发**，水平穿出所属分块后**立刻在框外走**。可以穿出，不可以斜穿。
3. **落点取目标节点该边的中点**。偏着进会让读者以为接的是某个角而不是整张卡。
4. **分块内要铺满**：标题 → 子帧 → 条目三段的留白大致均分。留白过大会被读成「这里还该有东西」。

## 8. 已知缺口

**通用自动布局引擎做不出这套图。** Mermaid / Graphviz 无法同时满足「同角色同尺寸」+
「固定基线节奏」+「正交零半径拐点」——它们按文字撑框、按算法选拐点。

严格合规有两条路：

1. **手写绝对坐标 SVG**（Phoenix 原图的做法）；
2. **用 `scripts/flow_svg.py` 的 `FlowGraph`**——固定尺寸网格 + 正交 A* 路由。节点按 `stage / row` 放进固定单元，长标签截断，连线只走节点与分块之间的通道。

Mermaid 只能做到近似：形状、配色、线型可以对齐，几何尺寸和基线做不到。
**用了 Mermaid 就不要声称合规**，只声称「视觉对齐」。

**管线决定（2026-10-29）：不路由。** `adapters/visual/capabilities.json` 的 `standalone.flow-diagram` 写明了 `routed: false`，入口是 `scripts/flow_svg.py`；不要把它塞进 archify / mermaid 的 manifest 再声称合规。

## 9. 生成器：从图数据出 SVG

`FlowGraph` 的输入是节点表 + 边表，不是坐标：

```bash
python scripts/flow_svg.py --input examples/flow/hermes-session.json \
  --palette gary --tokens \
  --html examples/flow/hermes-session.html \
  --css ../../tokens/base.css \
  examples/flow/hermes-session.svg
```

```json
{
  "stages": [{"id": "input", "title": "输入", "role": "input"}],
  "nodes": [{"id": "user", "role": "input", "kind": "capsule", "title": "用户消息", "sub": "本轮唯一原始输入", "detail": "用户本轮的唯一原始输入；不在这里做解释。", "stage": 0, "row": 0}],
  "edges": [{"from": "user", "to": "intent", "kind": "solid"}]
}
```

- `kind`：`card`（120×70）或 `capsule`（默认 h=36；报告页 h=54，放名称 + 摘要两行）。
- `sub`：节点摘要，**每个节点必须有**；卡片显示在标题下，胶囊显示在名称下。
- `detail`：节点详情，**报告页每个节点必须有**；点击节点后在该节点弹出玻璃详情卡（foreignObject），Esc / 点空白 / 关闭按钮收起。
- `stage`：列，画成 1px 虚线分块；`row`：行。行号按**阶段内部**从 0 起算，所以所有阶段块顶部对齐；单节点阶段自然成为短块。
- `kind` 为 `dashed` 的边只用于非主路径（辅助输入 / 异步回报 / 重试回路）。
- `palette='gary', tokens=True` 输出 `var(--gary-*)`；`--html` 生成可直接过 `verify_preview_page.py` 的预览页。
- **多张图内联在同一页**：`FlowGraph` 自动给 marker / filter 加内容 hash 前缀；两张内容完全相同的图重复内联时，显式传 `id_prefix` 区分，否则浏览器只认第一份定义、后几张箭头会消失。
- 自动布局只解决「坐标」；虚线语义、胶囊间距、落点是否读起来顺，仍按 §7.1 人读一遍。

## 10. 报告页呈现（03 定稿）

当这张图嵌进 Gary-UI 报告页、要当页面主角时，用 `--report`：

```bash
python scripts/flow_svg.py --input examples/flow/hermes-session.json \
  --palette gary --tokens --report \
  --html examples/flow/hermes-session.html \
  --css ../../tokens/base.css \
  examples/flow/hermes-session.svg
```

它只改呈现层，不动几何、线型、色板：

- **阶段框退成中性**：1px 实线、24% 不透明、无填充；阶段标题 14/500、`letter-spacing .12em`、text-tertiary。虚线只留给边，不再和分块边框打架。
- **卡片是玻璃的**：填充 `--gary-card-surface-top`（半透明）+ 一层柔和落影（dy 6 / blur 12 / 35%）；不做发光、不做内高光。卡片仍然只染描边，玻璃只负责「浮起来」。
- **卡片宽度自适应**：整图按最长标题 / 副标题统一宽度（120–260px）；先按 14px 量像素，放不下退 12px，仍放不下才截断。**不按字符数截断**——`DNS 公网解析`、`archos core-flow`、`Console legacy 视图` 这类标签会完整显示。
- **每个节点都有名称 + 摘要**：卡片标题下 11px 摘要；胶囊报告页 h=54，名称 14 + 摘要 11 两行。`sub` 缺失直接报错，不再静默留白。
- **点击节点弹出详情卡**：`detail` 必填；卡片用 `foreignObject` 浮在节点上方 / 下方（放不下时自动换边），玻璃填充 + 落影，Esc / 点空白 / 关闭按钮收起。
- **主路径成为唯一亮线**：`edges[].emphasis='main'` 的边用 text-primary；`side` 边 52% 不透明。读者先看流程，再看角色。
- **端点水滴 13×13**：箭尖 `refX 11.2` 贴住框边，圆背收线；主路径亮白、旁支灰。每条 line/polyline 必须带 `marker-end`，漏了就判红。
- **删掉解释层**：无眉标、无四色图例；标题下一句副标题；底部一行 key：实线 = 主路径 · 虚线 = 辅助 / 异步 · 描边色 = 角色。
- **页面垂直居中**：六个阶段块顶部对齐；首尾块可以短一截，不强行补空行（补空行会被读成「这里还该有东西」）。
- **窄预览窗不压字号**：SVG 的 `min-width` 设为 `0.85 × 图宽`，宁可横向滚动，也不把 14px 压成 8px；4 阶段图通常仍能整幅放下。
- **fan-in / fan-out 用 `from_offset` / `to_offset` 分开**：结果校验三个入口不要叠成一个点；偏移量以 `±12–14px` 为宜，落在边的中点附近。
